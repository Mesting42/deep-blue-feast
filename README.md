# 深蓝食界

一款侧视海洋吞噬成长游戏。从一尾小鱼开始，探索晨光珊瑚湾、海藻沉船区与深蓝裂谷，通过捕食、进化和能力搭配挑战大型掠食者。

项目使用 TypeScript、Vite、Canvas 2D 与 Web Audio。核心玩法、鱼群、碰撞、地图、关卡、界面均为本项目实现，没有使用完整游戏模板。正式运行没有账号、后端、第三方素材请求或 AI 服务依赖。

## 启动与构建

需要 Node.js 20.19+ 或 22.12+ 和 npm。首次准备依赖：

```powershell
cd 'D:\AnLi\深蓝食界'
npm ci
npm run dev
```

开发地址：[http://127.0.0.1:5178/](http://127.0.0.1:5178/)。端口使用 strictPort，遇到占用会报错，不停止或替换其他项目的服务。

```powershell
npm run build
npm run preview
```

生产预览地址：[http://127.0.0.1:4178/](http://127.0.0.1:4178/)。`dist/` 是可独立部署的静态网站，可将其作为 Cloudflare Pages 的输出目录；构建命令为 `npm run build`。当前资源路径按站点根路径配置。

生产版本首次完整打开后，会尝试缓存全部本地资源，后续可离线打开。离线缓存需要 HTTPS 或 localhost；浏览器拒绝缓存不影响联网访问。开发版本不注册 Service Worker，以免旧资源干扰热更新。

请通过上述本地服务或静态托管地址运行，不要直接双击 `dist/index.html` 使用 `file://` 打开。

如果希望在同一局域网的真实手机上检查，可自行运行 `npm run dev -- --host 0.0.0.0`，用手机访问电脑的局域网地址和 5178 端口；需由本机网络环境允许访问。本次交付没有修改系统防火墙规则。

## 玩法与操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 游动 | WASD 或方向键 | 左侧虚拟摇杆 |
| 冲刺 | 按住 Shift | 按住右侧冲刺 |
| 主动能力 | E | 右侧技能 |
| 情境交互 | F | 右侧交互 |
| 暂停 | Esc / 暂停按钮 | 暂停按钮 |

可在设置中启用鼠标跟随；键盘有输入时优先使用键盘。触屏优先横屏，竖屏会给出旋转引导并暂停，转回后手动继续。

- **绿色圆点**：体型足够，面向猎物并靠近鱼嘴可自动吞噬。
- **浅色空心圆**：体型接近，尚不能捕食。
- **红色尖角**：碰撞危险，应避让或继续成长。
- **紫色棘刺图案**：毒性 / 棘刺目标，即使可吞噬也有毒伤；净海鳞片可减免。
- **金色星辉**：奖励生物，可恢复生命并减少部分技能冷却。
- **橙色头部弱点**：精英的特殊咬击窗口，每轮只能结算一次。

玩家体型达到普通目标的 **1.2 倍**才有吞噬资格；此外还需满足鱼嘴范围、朝向和无遮挡条件。高速捕食使用连续扫掠检测，不使用随机成功率。

## 已实现内容

- 海域旅程、无尽生存、自由练习三种模式。
- 三个视觉与地形不同的海域、海域过渡、支路秘藏、安全庇护所、危险水流 / 热泉。
- 17 种生物配置和 13 类基本轮廓，分层鱼体、尾鳍与胸鳍动画、群体分离和巡游 / 逃散 / 追击 / 伏击行为。
- 五个成长阶段，从初始 40 cm 的小鱼开始，吃掉更小的鱼后逐帧长大；鱼体轮廓与鳍部连续成熟，镜头和可捕食提示随之变化。
- 鱼头先引导、身体与尾部依次跟随的上下游动，常态俯仰约 32°；左右沿小弧线弯身掉头，鱼嘴与关节中线共用判定。
- 开局之后的新增鱼从左右画面之外游入，普通补鱼与无尽事件共用刷新规则。
- 四种主动能力：水流爆发、墨云掩护、电流脉冲、鳞甲护体。
- 18 种不重复进化，包含机动、隐蔽、防御、控制和连续成长方向。
- 两种区域精英与一个两阶段最终掠食者，含冲撞、尾扫、水流和弱点窗口。
- 有约束的随机地形、鱼群、精英位置、信标任务组合、支路事件、进化选项与无尽潮汐事件。
- 主菜单、模式选择、三步教学、HUD、进化、事件、图鉴、暂停、设置、胜负结算、本地纪录。
- 独立音量、程序合成环境音乐和音效、首次手势解锁、后台暂停。
- 有版本号的独立本地存档、安全检查点恢复、损坏数据验证、设置 / 图鉴 / 纪录保存。
- 无尽体型和活跃生态数量上限；重新开始完整重建状态。

海域旅程面向首次探索的节奏目标为 15–25 分钟；熟练程度、探索选择和随机种子会影响实际用时，没有强制等待或饥饿条。

## 关键挑战规则

依 HUD 完成信标与本地鱼群目标、达到对应成长阶段后，区域精英开始主动挑战。躲开预警攻击，再面向橙色头部弱点靠近咬击。

- 银刃梭王：三次弱点咬击。
- 沉船巨鳗：四次弱点咬击，增加回旋 / 尾扫压力。
- 深渊冠鲸：六次弱点咬击，三次后进入第二阶段并缩短预警。冲撞遗迹石柱会延长弱点窗口。尾扫需离开橙色范围，水流需进入青色安全扇区。

最终挑战完成后停止世界伤害与危险生成，先播放胜利反馈，再展示用时、捕食、探索、进化、体型和得分。

## 测试命令

```powershell
npm test
npm run test:journey -- 73
npm run test:endurance
npm run build
```

`npm test` 包含 32 项测试，覆盖高刷新率时钟、键盘 / 多指针输入、关节跟随、小弧线掉头、中途反向、鱼嘴、渐进成长、画外入场、伤害保护、暂停、200 个地图种子、存档、技能与防重复结算。

`test:journey` 的驾驶员只提供正常移动、冲刺、技能、交互和进化选择，不修改成长、生命、敌人命中次数或胜利状态。它验证完整引擎流程，不冒充浏览器实际游玩。

`test:endurance` 在初始安全水域推进 30 分钟无尽模式逻辑，验证事件和对象数量；它不代表真机 30 分钟帧率或散热测试。

浏览器测试、截图与设备验证边界见 [docs/TESTING.md](docs/TESTING.md)。系统结构与扩展方法见 [docs/HANDOFF.md](docs/HANDOFF.md)。插画素材与生成提示词见 [docs/ART.md](docs/ART.md)。

## 存档与运行边界

存储命名空间为 `deep-blue-feast:v1:`。海域旅程约每 30 秒自动保存，庇护所、信标、进化和海域推进也会触发保存。继续时恢复到当前海域的庇护所，并恢复生命与短暂保护；不恢复敌人追击、进行中的攻击或临时护盾。

纪录只属于当前浏览器和当前站点来源。开发端口与生产预览端口不同，因此各自拥有独立的本地存档。清除浏览器站点数据也会清除这些纪录。

本项目没有在线多人、账号同步、云存档或服务器排行榜。声音为本地程序合成。移动端真机、Safari 和不同 GPU 的最终表现需要在对应设备上继续验证；浏览器模拟结果不等同于真机测试。

## 交付包

`release/深蓝食界-源码.zip` 包含源码、原始插画、压缩素材、配置、测试和交接文档，不打包 `node_modules`。解压后运行 `npm ci` 安装依赖。

`release/深蓝食界-静态网页.zip` 包含 `dist/` 的全部可部署文件。解压后的 `index.html` 应位于静态站点根目录；使用 HTTP / HTTPS 服务访问。
