# 测试与验收记录

日期：2026-10-24（Asia/Shanghai）。本记录区分浏览器实玩、视口模拟和纯引擎测试，不将测试夹具或直接修改状态当作实玩通关。

## 本轮关节游动与小弧线掉头复测

主角改为鱼头、躯干、尾部依次跟随的中线鱼体。常态俯仰上限约 32°，掉头约 0.4 秒，实际移动沿小弧线过渡。浏览器通过练习菜单选择阶段五以放大观察；没有改动旅程的成长或存档，测试前保存了原有旅程。

- 上游初始观察到 headAngle≈-0.467、bodyAngle≈-0.216、tailAngle≈-0.057；随后的反向下游观察到鱼头已转为 +0.342，而身体与尾部仍分别为 -0.168 / -0.449，确认跟随顺序清楚。
- 左右掉头观察到关节先后转向、身体连续弯曲，实际位置沿小弧线改变；中途反向不排队执行旧转身，松开后实际移动停止。
- 手机 844 × 390 的真实按钮操作验证：摇杆俯仰、左右换向、按住冲刺同时反向，体力从 100 降至约 79.6，鱼头与尾部顺序跟随。
- 平板 1024 × 768 验证斜向摇杆、六次快速左右输入、最终方向恢复；随后通过正常摇杆追逐成功吞噬 **34 条鱼**，没有直接调用吞噬方法。
- 1440 × 900 / 844 × 390 / 1024 × 768 的最终构建画面确认通过；从运行状态切至 390 × 844 后自动变为 paused 并显示旋转引导。检查时没有控制台错误。
- 当前 32 项测试与三个正常输入主线种子全部通过；三个种子的本轮用时约 **16:01、15:06、15:20**，详细数值见 JSON。

## 累计浏览器实玩（含此前验收）

使用应用内 Chromium 浏览器和正常键盘、鼠标跟随、虚拟摇杆及 UI 按钮操作。浏览器测试不修改玩家成长、生命、敌人命中次数，不调用胜利函数。

- 已实玩教学、初始捕食、成长选择、三片海域、信标、秘藏、两种区域精英和最终掠食者，并进入胜利结算。最终结算为 **15:22、589 条捕食、12 项探索、7 项进化、43,519 分**。旅途中曾因构建修复保存并从安全检查点继续；此时间是游戏累计时间，包含旧版前半程，并非最终版本从零开始的一次未中断计时。
- 此前水平转向版本中，正常操作完成最终掠食者六次弱点咬击，覆盖第二阶段水流、尾扫与冲撞；本轮关节版本的最终挑战由三个正常输入引擎旅程重新验证。
- 另开全新旅程，验证初始 `size=20`、体长 40 cm、阶段 1、100 生命、零进化、零成长，未继承上一局体型或练习技能。
- 新局实玩捕食 12 条沙丁鱼后，成长值 15.12，实际 size 由 20 平滑增加至约 21.249（体长约 42.5 cm）。一口食物先积累成长，随后逐帧变大，没有阶段换鱼体造成的突然变窄。
- 读取得到最近 28 条实际补充鱼的出生记录，全部满足整条鱼处于其出生时画面左侧或右侧之外。普通补鱼与无尽事件的共同规则另有自动测试。
- 此前轻量姿态四向按键实测：上游俯仰约 -0.38，下游约 +0.378，左右换向到达 facing=-1 / +1；该结果保留为历史基线，主角本轮已采用三段关节与中线绘制。
- 已检查图鉴、设置、保存返回、继续、暂停与重新开始。图鉴打开时，游戏时钟不推进；切换窗口与竖屏会暂停。

`npm test`：**32 项通过，0 项失败**。

- 高速鱼嘴扫掠、尾部拒绝、姿态与鱼嘴一致、普通鱼轻量侧身最窄时禁止吞噬、奖励防重。
- 初始体型、吞噬资格、实际体型逐帧增长、成长上限与重新开始。
- 主角头 / 身 / 尾跟随、小弧线位移与中线长度、中途反向、弯身 / 斜向 / 冲刺的嘴尖一致、松手停止；普通鱼轻量俯仰和侧身兼容。
- 左右画外生成、镜头范围与地图边界、无位置时跳过、大型入场者超出普通 AI 距离仍游动。
- 伤害保护、护盾优先、四种技能、进化唯一与耗尽、事件原子结算、胜负只结算一次。
- 200 个地图种子的中心通路、奖励位置与出生安全空间。
- 版本化存档、非顺序站点、待选进化、安全恢复和损坏数据拒绝。
- 连续渲染最终出口时 Canvas save / restore 成对，防止状态栈泄漏。

正常输入引擎驾驶员通过三个种子全流程。它只读状态，提供移动、冲刺、技能、交互与进化选择；不会直接加成长、回血、削减敌人或调用胜利。具体用时和统计保存于 [test-results.json](test-results.json)。驾驶员会换掉长时间追不上的猎物并游回开阔水道；它验证引擎完整流程，不替代浏览器实玩。

此前无尽耐久：推进 **30.0007 分钟逻辑时间、20 次生态事件**，存活鱼 323 条，观察到的对象数量峰值 329，玩家生命 100。测试停留在初始庇护水域，墙钟运行约 21 秒。本轮仅调整主角转向与绘制，未重复该耐久；**不属于 30 分钟浏览器性能或真机温升测试**。

`npm run build`：TypeScript 检查与 Vite 静态构建通过；生产输出包括 HTML、JS、CSS、本地插画、标识和 Service Worker，无外部素材运行依赖。

## 离线验证

此前实际停止本项目的 4178 预览进程，然后在同一浏览器刷新生产页面。修复后主菜单、插画、CSS、JS 均正常载入，继续本地存档后按 D 游动约 221 世界像素，游戏时钟推进约 1.23 秒，验证可离线游玩。随后恢复预览服务。本轮未改动离线安装逻辑。

离线失败曾发现于预览服务器的 `Vary: Origin`：预缓存请求与模块脚本的请求 Origin 不同，导致有缓存仍无法匹配。已对本项目静态缓存使用 `ignoreVary`，并处理旧 HTML / 哈希资源跨版本切换。缓存仅保证首次完整安装之后、同一浏览器和站点来源下的离线访问；首次就离线或浏览器拒绝缓存不在此保证内。

## 已修复的主要问题

1. 高刷新率下时间余量丢失，导致逻辑推进不足。
2. 手机技能只绑定到隐藏的桌面入口；菜单低高度溢出。
3. 持续按住冲刺在低体力阈值交替恢复，形成间歇无限加速。
4. 只存信标数量，导致非顺序收集恢复错误；待选进化遗漏。
5. 大鱼占满附近生态时无法补充可捕食食物。
6. 最终出口绘制提前返回但未 restore，造成鱼体离开画面与 Canvas 状态泄漏。
7. 整条鱼硬转及左右突然翻面；阶段切换鱼体轮廓突变。
8. 新鱼在画面内突然生成；极大镜头下新鱼停在常规 AI 更新范围外。
9. 生产页面更新与离线资源匹配失败。
